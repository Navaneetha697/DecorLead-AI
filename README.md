# DecorLead AI 🏠

## Home Decor Buyer Finder & Outreach Platform

DecorLead AI is an API-powered web application that helps home decor sellers discover potential business buyers in the United States and prepare personalized outreach emails.

## Features

- 🔎 Find potential home decor business leads
- 🇺🇸 Search businesses by US location
- 🏪 Search by buyer type
- 📍 Display business location and contact details
- 📞 Display available phone numbers
- 📧 Retrieve available business email addresses
- ✉️ Generate personalized outreach emails
- 🚀 Send emails through the Resend Email API
- 📊 No CSV file upload required
- 🔐 API keys stored securely in environment variables

## How It Works

```text

        ↓

        ↓
